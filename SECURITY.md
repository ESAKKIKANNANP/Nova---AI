# Security Policy

## Supported Versions
Only the latest major version (`v1.x`) is currently receiving security updates.

## Reporting a Vulnerability

Security is a top priority for the Autonomous Data Scientist platform. We take vulnerabilities in our codebase, dependencies, and Docker images very seriously.

If you discover a security vulnerability, please **DO NOT** open a public issue. 
Instead, please send an email to `security@yourdomain.com`.

We will acknowledge receipt of your vulnerability report within 24 hours and strive to send you regular updates about our progress. If you report a vulnerability that significantly impacts the platform, you may be eligible for a bounty.
